# osTicket Helpdesk Lab

A hands-on IT Helpdesk lab demonstrating the deployment,
configuration, and use of osTicket as a ticketing system.

## Project Overview

This project simulates a real-world Tier 1 IT Helpdesk
environment using osTicket.

## Environment

- osTicket
- Windows
- Azure VM
- MySQL
- Apache
- Web-based helpdesk environment

## Project Sections

### 1. Installation & Prerequisites

Configured the environment and installed osTicket.

### 2. Post-Installation Configuration

Configured departments, teams, staff accounts,
help topics, SLAs, priorities, and other helpdesk settings.

### 3. Ticket Lifecycle

Created realistic helpdesk tickets and demonstrated
the process from ticket creation through assignment,
troubleshooting, resolution, and closure.

## Skills Demonstrated

- Helpdesk ticket management
- Ticket prioritization
- Ticket assignment
- Incident documentation
- Troubleshooting
- Escalation
- Customer support workflow
- IT service management concepts
